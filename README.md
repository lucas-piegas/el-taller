# El Taller

Llega chatarra irreconocible. La limpiás con el dedo y descubrís qué era.

Este repositorio no tiene el código: es **solo el build web**, publicado para
poder abrir el juego desde un teléfono sin pasar por ninguna tienda.

**Jugar:** https://lucas-piegas.github.io/el-taller/

En iPhone, *Compartir → Agregar a inicio* lo deja como un ícono más: abre a
pantalla completa y, a partir de la segunda vez, anda sin conexión.

Hecho con Godot 4.7. En desarrollo.
